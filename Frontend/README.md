# IRISiv — Person 1 Frontend Specification Package

This package contains the complete planning/specification documents for the IRISiv frontend developer.

1. `PERSON-1-HANDOFF.md` — Start here. Complete assignment and acceptance criteria.
2. `PRD.md` — Product requirements and frontend scope.
3. `UI-UX-SPEC.md` — Design system and UX rules.
4. `WIREFRAMES.md` — Structural wireframes for key screens.
5. `USER-FLOW.md` — Complete user and project flows.
6. `TECH-STACK.md` — Frontend technology and architecture rules.
7. `COMPONENT-STRUCTURE.md` — Suggested page/component organization.
8. `DESIGN-REFERENCES.md` — Visual direction and reference categories.

# IRISiv — Design References & Visual Direction

## 1. Reference Categories

The frontend should take inspiration from these categories rather than copying any one product:

### B2B SaaS
Use for:
- Dashboard hierarchy
- Tables
- Navigation
- Filters
- Settings

### Fintech
Use for:
- Financial KPI cards
- Payment status
- Transaction history
- Trust indicators

### Enterprise Workflow Platforms
Use for:
- Project lifecycle
- Approvals
- Activity history
- Audit-oriented UI

### Impact / ESG Platforms
Use for:
- Beneficiary metrics
- Impact reporting
- Project outcomes
- Evidence presentation

## 2. Visual Target

IRISiv should look closer to a serious enterprise platform than a student project.

Desired impression:

**"This could become a real CSR operations platform."**

## 3. Visual Priorities

Priority 1:
- Information hierarchy
- Project lifecycle clarity
- Trust/verification visibility

Priority 2:
- Clean dashboards
- Excellent tables
- Strong forms

Priority 3:
- Analytics and charts

Priority 4:
- Animation/decorative polish

## 4. Screenshot/Reference Usage

If external screenshots are used during development:
- Use them as inspiration only.
- Do not copy branding.
- Do not copy proprietary assets.
- Recreate the design using our own IRISiv design system.

## 5. Hero Screens

Spend the most visual effort on:

1. Corporate Dashboard
2. Project Details + Lifecycle
3. Proposal Comparison + AI Recommendation
4. AI Verification Result
5. Impact Report

These screens are central to the hackathon story.

These documents define the backend implementation around the finalized IRISiv workflow:

→ Corporate approval/funding
→ Opportunity
→ Business proposals
→ AI evaluation
→ Corporate business selection
→ Contract
→ Advance payment state
→ Business execution
→ Delivery + evidence
→ NGO verification
→ AI verification
→ Corporate review
→ Final payment state
→ Project completion
→ Impact report

Do not redesign this workflow without team approval.
